------------CITAÇÃO SIMPLES------------



<q> para abrir a tag para criar uma citação

exemplo:<p>Como diria o pai de um amigo:<q>O computador é um burro muito rápido</q>.</p>

resultado: Como diria o pai de um amigo:"O computador é um burro muito rápido".

q é semântica, INDICA que é uma citação, no caso de coisas que não são citações compensa muito mais "só" mandar as aspas manualmente.




------------CITAÇÃO COMPLETA------------



<blockquote> para abrir a tag para criar uma citação completa, uma que encaixa textos maiores.

cite: é para colocar a fonte de onde você tirou a citação, ela não aparece no site, mas os mecanismos de busca e o Google vai entender que você está referenciando algo.

</blockquote>

------------ TAG <SPAN> ---------


É UMA TAG HTML INLINE, SERVE PARA MARCAR UMA PEQUENA PARTE DO TEXTO, NORMALMENTE UMA PALAVRA OU TRECHO, PARA DEPOIS ESTILIZAR COM CSS.



exemplo:

<p>Eu gosto de <span>Android</span>.</p>



resultado:

A palavra Android fica separada do restante do texto para receber estilo.



EXEMPLO COM CLASS:

<p>Eu gosto de <span class="destaque">Android</span>.</p>

    .destaque {
        color: green;
        font-weight: bold;
    }
</style>



resultado:

A palavra Android ficará verde e em negrito.



QUANDO USAR:

✔ destacar palavra
✔ colorir parte do texto
✔ aplicar class em trecho pequeno
✔ aplicar id em palavra específica

--------- FONT-VARIANT e TEXT-TRANSFORM ---------



Ambos mudam a capitalização do texto, mas de formas diferentes.

    font-variant: small-caps;
    → transforma letras minúsculas em MAIÚSCULAS menores
    → as letras que já eram maiúsculas ficam maiores
    → resultado: visual elegante, todas maiúsculas mas com
      hierarquia de tamanho

        h1 { font-variant: small-caps; }
        "cordel moderno" → CORDEL MODERNO (com tamanhos diferentes)


    text-transform: uppercase;
    → transforma TUDO em maiúsculo com o mesmo tamanho
    → sem diferença de tamanho entre as letras

        h1 { text-transform: uppercase; }
        "cordel moderno" → CORDEL MODERNO (tudo igual)

    Outros valores de text-transform:
        text-transform: lowercase;   → tudo minúsculo
        text-transform: capitalize;  → Primeira Letra De Cada Palavra

--------- LINE-HEIGHT (ALTURA DA LINHA) ---------



Define o espaço vertical entre as linhas de um texto.
É como o espaçamento de linha no Word.

    line-height: 1;      → linhas coladas (sem espaço extra)
    line-height: 1.5;    → espaçamento confortável para leitura
    line-height: 2em;    → duas vezes o tamanho da fonte atual
    line-height: 2;      → mesma coisa, sem precisar da unidade

    Exemplo:
        section {
            font-size: 16px;
            line-height: 2em;  → espaço entre linhas = 32px
        }

    Dica: para textos longos, line-height entre 1.5 e 2
    melhora muito a leitura.




--------- TEXT-SHADOW (SOMBRA NO TEXTO) ---------



Adiciona sombra ao texto. A sintaxe tem 4 valores:

    text-shadow: x  y  desfoque  cor;

    x        → deslocamento horizontal (positivo = direita)
    y        → deslocamento vertical   (positivo = baixo)
    desfoque → quanto a sombra espalha (0 = sombra dura)
    cor      → cor da sombra


    Exemplos:

    text-shadow: 1px 1px 0px black;
    → sombra dura, 1px para direita e 1px para baixo
    → usada para dar legibilidade em cima de imagem

    text-shadow: 2px 2px 5px rgba(0,0,0,0.5);
    → sombra suave e semitransparente

    text-shadow: 0px 0px 8px white;
    → brilho ao redor do texto (efeito neon)

    text-shadow: -1px -1px 0px black;
    → sombra para cima e para a esquerda

    Múltiplas sombras (separadas por vírgula):
    text-shadow: 1px 1px 0px black, 0px 0px 10px white;

--------- COMO CARREGAR FONTES BAIXADAS ---------

- @font face + enter

- é o parametro criado para permitir fontes baixadas

- tipos de format()
 - opentype (otf)
 - truetype (ttf)
 - embedded - opentype
 - truetype-aat (Apple Advanced Typography)
 - svg

 - todos os nomes da fonte devem ser iguais
 - se quando baixar, vier mais um arquivo, coloque a url dos dois arquivos


<title>Fontes Externas</title>
<style>
    @font-face {
        font-family:'FutureTech';
        src: url('FutureTech.ttf') format('truetype');
        font-weight: normal;
        font-style: normal;
    }
    body {
        font-family: Arial, Helvetica, sans-serif;
    }
    
    h1 {
        font-family: 'FutureTech', Times, serif;
        font-size: 3em;
    }

</style>
